# ⚡ Superpower: Zero-Collision Agent Fleets

Traditional AI coding tools lock your editor and modify your working branch directly. If you want to work on 5 issues at once, you have to wait or risk merge chaos.

**Fleet Agent IDE** allows you to dispatch dozens of agents simultaneously. Each agent gets its own physical directory and Git branch via worktrees. You can continue typing in your IDE while 10 agents refactor legacy endpoints, write documentation, and add test coverage in parallel.
