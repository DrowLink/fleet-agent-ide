# ADR 0003: LangGraph Autonomous Self-Healing Validation Loop

## Context
Code generated by LLMs frequently contains syntax or runtime bugs. Traditional linear prompts require human intervention to paste test output back to the agent.

## Decision
We structure the worker agent as a cyclical **LangGraph StateGraph** that executes code modifications, runs automated tests in the isolated worktree, feeds `stderr`/`stdout` back to the model, and iterates autonomously up to `max_retries`.

## Consequences
- **Positive**: High first-pass success rate; tasks arrive in `READY_TO_MERGE` only when local test suites pass cleanly.
- **Negative**: Adds token consumption and execution latency per validation cycle.
